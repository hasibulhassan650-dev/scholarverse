# ScholarVerse 🎓
### Funded Master's Command Centre & Academic Directory

Live Web Application: **[https://hasibulhassan650-dev.github.io/scholarverse/](https://hasibulhassan650-dev.github.io/scholarverse/)**

Built for **Hasibul Hasan Santo, CFA** (Economics BSS, Treasury ALM & Money Market at City Bank PLC).

- **14 Interactive Views:** Master Dashboard, Interactive Month Calendar, Missions with XP tracking, Documents Tracker, Universities (50 Ranked + 82 Census), Faculty Directory with Interactive Dossiers, Citations Audit, and Dead Ends.
- **100% Client-Side:** Zero runtime dependencies, persistent local storage across visits.
